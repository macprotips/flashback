The provider directories are also useful for titles that are not hand-picked.
[DOSGames.com](https://dosgames.com/) describes its catalog as freeware,
shareware, and public-domain DOS downloads rather than warez or abandonware.
[DOS Games Archive](https://www.dosgamesarchive.com/) records a license on each
download. [ScummVM](https://www.scummvm.org/games/) publishes freeware adventure
game packages and checksums. [itch.io’s DOS category](https://itch.io/games/free/tag-dos)
contains current creator-published DOS games. A title from any directory still
requires its own source and compatibility review before Flashback recommends it.
